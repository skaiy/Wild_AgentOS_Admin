# 当前版本范围与边界（v0.2.0-alpha）

:::warning
平台处于 Alpha 阶段。以下能力可在测试环境完整验证，但接口、字段与默认配置仍可能出现不兼容变更，生产化前需完成性能、安全与容灾评估。
:::

## 1. 已交付能力范围

### 1.1 Agent 与 Skill

- 用户态 Agent 的创建、编辑、删除与持久化，刷新后由后端接口恢复。
- Agent 可挂载多个 Skill、知识包与模型能力槽（`chat` / `vision`）。
- 应用级 Skill（`skill://`）注册、编辑、删除、输入输出 Schema、准入流水线与发布状态。
- Git 仓库 Skill 导入；系统级 `iri://` Skill 在界面保持只读。
- Prompt 版本创建、激活、灰度比例与 resolve 结果查询。

### 1.2 知识中心

- 知识库分类的创建、编辑与删除。
- 向量库、图谱库的创建与分类关联。
- 向量文档上传、文档台账、原文预览与重新索引。
- CSV、JSONL、N-Triples 等结构化图谱数据导入（支持替换/追加）。
- SPARQL 查询、三元组浏览与图谱可视化。
- 知识包组合分类、图谱库与向量库，并由 Agent 挂载。

### 1.3 模型与网关

- OpenAI 兼容 Provider 注册、远端型号发现、连通性测试。
- 模型资源登记 chat / vision / embedding / audio / realtime 模态与向量维度。
- 默认网关模型与 Embedding 资源激活。

### 1.4 运行与运维

- 任务创建、SSE 流式输出、状态、计划与执行明细。
- 运行时配置快照、健康状态与运行指标。
- L0-L3 记忆指标与 L2 共享黑板查看。
- 批处理状态、窗口指标、抽取指标与启停操作。
- Guard 统计、审计记录与调用方 API 密钥管理。

## 3. 已知边界

- 外部业务系统（工单、库存、BOM、VIN、车机与客服渠道）尚未接入，相关能力需在对接后验证。
- MCP Server 登记当前为元数据登记，连通探活与工具清单同步依赖后端实现与部署配置。
- 向量检索效果取决于生效的 Embedding 资源与索引维度，切换 Embedding 模型需重建向量索引。
- 大规模知识图谱（数万节点级）在管理端 3D 可视化下渲染负载较高，建议先用 SPARQL 或按子图筛选后查看。
- 管理端登录为演示用本地登录，生产部署需接入正式身份体系（JWT / `X-Identity`）与严格模式 RBAC。

## 4. 升级注意事项

- 配置更新走 `PUT /api/v1/config`，模型段为整体替换语义；提交时保留既有 Provider 与资源，密钥留空表示沿用原值。
- 更新前建议备份运行目录下的配置覆盖文件与数据目录。
- 前端发布需重新构建并内嵌文档站产物，确保 `/docs-site/` 子路径资源可访问。
