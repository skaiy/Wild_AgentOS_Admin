## 版本记录约定

- 版本号按平台整体能力递进，前端管理台与后端内核同版本号发布。
- 平台处于 `0.x` Alpha 阶段：`0.1.x` 为能力搭建期，`0.2.x` 为当前迭代期；进入 Beta（`0.9.x`）前不保证接口向后兼容。
- Agent、Skill、知识包等业务对象自带的版本号（如 `v1.0.0`）为资源自身版本，与平台版本无关。
- 接口、页面字段或默认配置调整后，应同步更新本页、当前版本范围、API 速查与验收步骤。
- 镜像与部署记录不在文档站维护，以部署环境的镜像标签为准。
