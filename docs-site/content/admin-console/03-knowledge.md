# 知识中心

## 功能定位

知识中心（菜单项「知识中心」，页面入口 `#knowledge`）是业务知识的统一治理入口，覆盖向量库与图谱库的分类与建库、原文档台账与索引重建、知识包组合体，以及本体层的对象/链接/动作/函数元模型与动作执行。页面标题「知识中心 (Knowledge Center)」，副标题「业务知识——向量库 / 图谱库、知识包组合体与本体层能力面」。直接进入本体页签可使用页面入口 `#ontology`。

智能体的检索范围由「知识包」决定：知识包关联分类、图知识库与向量知识库，智能体再挂载知识包，从而实现包间隔离。

## 页面结构（区块/Tab/卡片，与代码一致）

顶部为「业务知识总览」统计条（6 个统计块）与实时徽标，右侧显示当前本体域：

| 统计块 | 取值 | 副标题 |
| :-- | :-- | :-- |
| 知识库总数 | `knowledge_bases.total` | 向量 N · 图谱 N |
| 知识包 | `knowledge_packs` | 无 |
| 本体对象类型 | `ontology.object_types` | 无 |
| 本体链接类型 | `ontology.link_types` | 无 |
| 动作类型 | `ontology.action_types` | 无 |
| 派生函数 | `ontology.functions` | 无 |

统计条下为两个一级 Tab：

**Tab 1「知识库」**

| 区块 | 内容 |
| :-- | :-- |
| 知识库分类 | 新增分类表单（名称 + 描述）与分类列表，支持行内编辑、保存、取消、删除 |
| 核心知识库列表 | 搜索框、「新建知识库」按钮，二级 Tab「向量数据库 / 图数据库」（带计数），表格列随类型切换 |
| 查看三元组抽屉 | 分批加载进度条、「3D 图谱 / 列表视图」切换、列表分页 |
| 原文档台账抽屉 | 文件名、大小、分块、状态、上传时间、原文预览，右上角「重建索引」 |
| 新建知识库弹窗 | 名称、描述、分类、类型二选一；向量库含分块策略与文件上传，图谱库含 Schema 与三元组文件 |
| 知识图谱实时查询 | SPARQL 输入框（默认查询语句）与「执行查询」，结果以 JSON 展示 |

**Tab 2「知识包与本体」**

| 区块 | 内容 |
| :-- | :-- |
| 知识包 (Knowledge Packs) | 卡片网格，显示图标、名称、版本、「内置」徽标、描述、分类/图库/向量库计数与名称标签、命名图与向量命名空间；右上角「新建知识包」，每卡可编辑/删除 |
| 本体元模型 Tab | 「3D 对象模型图」「对象类型」「链接类型」「动作类型」「函数」五个页签，均带数量徽标 |
| 动作执行器弹窗 | 目标对象主键输入 + 按参数类型动态生成的表单，底部「预览 (dry_run)」与「执行写回」 |
| 知识包编辑器弹窗 | 名称、描述、版本、图标、颜色，三个多选列表（分类/图知识库/向量知识库），勾选向量库后出现文本灌入区 |

## 关键操作（编号步骤）

1. **建分类**：在「知识库分类」输入分类名称（如「动力电池」）与可选描述，点击「新增分类」；已有分类可点铅笔进入行内编辑后保存，或点垃圾桶删除。
2. **新建向量库**：切到「向量数据库」页签，点击「新建知识库」，填写名称（必填）、描述、分类，类型选「向量数据库 (Vector DB)」，选择分块策略并选择文件，点击「创建并开始索引」。
3. **新建图谱库**：类型选「图数据库 (Graph DB)」，可填写图谱 Schema 文本（作为命名图元三元组保存）并上传三元组文件，点击「创建并开始索引」。
4. **查看摄取结果**：创建成功后弹窗保留结果提示，向量库显示「已写入 N 个分块（应用策略：…）」并列出被跳过的文件及原因；图谱库显示写入三元组、实体、关系数与 Schema 是否保存。无摄取动作时弹窗直接关闭。
5. **检索与筛选**：在列表右上搜索框输入关键词，按名称、命名图、命名空间、分类、描述做前端过滤。
6. **查看三元组**：图谱库行点击「查看三元组」，抽屉先查询总数再按每批 5000 条分页拉取全量，进度条显示「已加载 / 总数」。
7. **切换图谱视图**：抽屉右上角切换「3D 图谱」与「列表视图」。3D 视图工具栏提供「聚焦全部节点」「自动旋转 / 停止自动旋转」「暂停渲染 / 继续渲染」「全屏查看」，点击节点或连线可查看详情浮层；列表视图按每页 100 条分页展示主语 → 谓语 → 宾语。
8. **查看原文档台账**：向量库行点击「查看文档」，抽屉列出已上传原文；状态为「已向量化 / 仅留底 / 失败」，已留底的文件可点「预览」打开原文直链。
9. **重建索引**：在台账抽屉点击「重建索引」，按当前向量服务与分块配置从原文重新分块入库；触发后提示「已触发重建（N 个文档），后台处理中…」，抽屉顶部显示重建状态与时间，列表会在数秒后自动刷新两次。
10. **执行 SPARQL**：在「知识图谱实时查询」编辑语句后点击「执行查询」，结果为空时显示「无结果」，异常时显示后端错误信息。
11. **新建知识包**：切到「知识包与本体」Tab，点击「新建知识包」，填写名称（必填）、描述、版本、图标、颜色，并在三个多选列表中勾选分类、图知识库、向量知识库，点击「保存」。
12. **向知识包灌入文本**：勾选至少一个向量库后出现灌入区，粘贴文本点击「灌入」，逐个向量库分块并写入，完成后提示「已灌入 N 个切片到 M 个向量库」。
13. **编辑/删除知识包**：卡片右上角铅笔进入编辑器（已失效的关联 ID 会在打开时自动过滤），垃圾桶删除并需确认「此操作不可撤销」。
14. **浏览本体元模型**：在「对象类型」中点击卡片展开属性列表（属性标签、必填星标、字段名、数据类型）；「链接类型」显示来源 → 目标与基数；「函数」显示作用对象、返回类型与表达式。
15. **执行动作**：在「动作类型」中点击「执行 / 预览」，填写目标对象主键与参数，先点「预览 (dry_run)」查看将执行的语句，确认无误后点「执行写回」，成功后提示已写回的命名图与语句条数。

## 字段与参数说明

| 字段 | 含义 | 约束或默认值 |
| :-- | :-- | :-- |
| 分类 `name` / `description` | 知识库分类名称与描述 | 名称非空才可提交；描述可选 |
| 知识库 `name` | 知识库名称 | 必填，为空时提示「请填写知识库名称」 |
| 知识库 `kb_type` | 知识库类型 | `vector` 或 `graph`；建库弹窗默认取当前所在页签 |
| 知识库 `category_id` | 所属分类 | 可选，未选则为「未分类」 |
| `graph` | 图谱库命名图 | 由后端生成；图谱页签表格首列展示 |
| `vector_namespace` | 向量库命名空间 | 由后端生成；向量页签表格第二列展示 |
| 分块策略 | 建库时的分块方式 | 下拉可选智能语义分块（默认）/ 固定长度（500 字符）/ 按段落标题；后端当前统一按固定长度分块，实际以返回的「应用策略」为准 |
| 向量库上传文件类型 | 可解析的文本文件 | 支持 TXT / Markdown / CSV / JSON / JSONL / LOG；PDF、Word 暂不支持解析，将被跳过 |
| 图谱导入文件类型 | 三元组文件 | 支持 CSV（`subject,predicate,object[,object_type]`）/ JSONL / N-Triples 等 |
| 文档状态 | 台账条目状态 | `ready` 显示「已向量化」；`stored` 显示「仅留底」；`failed` 显示「失败」 |
| `skipped_reason` / `persist_warning` | 跳过原因 / 留底告警 | 存在时在文件名下方以琥珀色提示 |
| 三元组批量参数 | 全量加载批大小与列表页大小 | 每批 5000 条；列表视图每页 100 条 |
| 知识包 `version` | 知识包版本 | 编辑器默认 `1.0.0` |
| 知识包 `icon` / `color` | 图标名与强调色 | 默认 `Package` / `sky`；颜色取内置色名，未识别时回退默认色 |
| 知识包 `category_ids` / `graph_kb_ids` / `vector_kb_ids` | 关联分类、图库、向量库 ID | 数组，默认空；内置包额外展示对象与链接数量 |
| 对象类型 `primary_key` / `properties` | 主键字段与属性定义 | 属性类型显示为文本/长文本/整数/数值/布尔/日期时间/枚举 |
| 链接类型 `cardinality` | 链接基数 | 一对一 / 一对多 / 多对一 / 多对多 |
| 动作 `target` | 目标对象主键值 | 部分动作强制要求填写目标主键，缺失时提示 |
| 动作 `params` | 动作参数键值 | 必填参数为空时提示「请填写必填参数：…」；整数/数值转数字，布尔转 `true`/`false`，空值不提交 |
| 动作 `dry_run` | 是否仅预览 | `true` 返回待执行语句不写库；`false` 写回命名图并返回生效语句数 |
| 写回效果 | 动作副作用类型 | 新建对象 / 更新属性 / 建立链接 |

## 排查与注意事项

- 「后端离线，无法加载知识库列表 / 分类 / 知识包 / 本体定义」：对应接口不可用，先恢复后端；统计条同时显示「—」。
- 上传的 PDF / Word 未生成分块：当前仅解析纯文本类文件，非文本文件会以跳过原因回写台账，需转换为 TXT / Markdown 后重新上传。
- 返回的「应用策略」与所选策略不一致：后端当前统一按固定长度分块，语义与标题策略将逐步启用，以「应用策略」为准。
- 文档状态为「仅留底」：原文已持久化但未完成向量化，可在台账中点「重建索引」重试。
- 变更向量服务或维度后检索异常：需对存量库重建索引，重建按当前生效的向量服务与分块配置从原文重新入库。
- 「重建索引」按钮不可点击：台账为空、正在重建（状态 `reindexing`）或请求进行中三种情况下按钮禁用。
- 图谱抽屉长时间停留在加载：命名图三元组量大时按每批 5000 条串行拉取，进度条会持续推进；三元组超过 5000 条的 3D 视图会降低渲染开销，可用工具栏暂停渲染或切换列表视图。
- 「该命名图暂无三元组数据」：图谱库已创建但未导入数据，或导入时选择了清空重写导致数据被替换。
- 3D 图谱标签为短名：节点与连线标签取 IRI 最后一段，完整 IRI 见详情浮层。
- 删除分类前请确认引用关系：知识库通过 `category_id` 关联分类，知识包通过 `category_ids` 关联分类，删除后相关展示会退化为未分类或按 ID 显示。
- 知识包编辑器打开后勾选项变少：编辑器会过滤掉已不存在的分类/知识库 ID，保存后即完成清理。
- 文本灌入提示「请先勾选至少一个向量库」：灌入操作作用于已勾选的向量库集合，需先完成勾选再灌入。
- 动作「执行写回」前务必先「预览 (dry_run)」：预览返回待执行语句且不写库，确认语句与目标命名图无误后再写回，写回结果不可自动撤销。
- 智能体回答未使用新知识：确认新建知识库已关联到知识包，且智能体已挂载该知识包；向量库还需完成索引（状态为「已向量化」）。
