# 运行时内核

页面入口：左侧导航「调试监控与运维 → 运行时内核」，深链 hash 为 `#runtime`。

## 功能定位

「运行时内核 (Runtime Kernel)」是语义内核的运行态观测面板，一屏回答三个问题：

1. **内核跑得怎么样**——事件总线、L2 黑板、检查点、技能注册数等实时指标；
2. **内核按什么参数在跑**——当前生效的网关、并行度、迭代上限与记忆容量配置；
3. **平台上有哪些业务智能体**——已注册智能体的启用状态、业务域、技能数量与来源（用户态／批处理）。

该页面为**只读观测页**：所有数值来自后端实时接口，页面本身不提供修改入口。参数调整请到「系统设置」页完成，配置保存后本页在下一轮轮询中刷新。

页面标题右侧的实时徽标含义：绿点「实时」表示已成功从后端取到数据；琥珀点「示例数据」表示后端未连接，此时各卡片数值统一显示为 `—`。

## 页面结构（区块/Tab/卡片，与代码一致）

页面为三栏栅格布局，左侧两列为观测区，右侧一列为配置区。

**左侧 · 语义内核运行时指标**

标题右侧带状态标签：后端在线时显示「实时 · 每 5s 刷新」，离线时显示「后端离线」。区块内为 6 张指标卡：

- 事件总线事件数
- 事件订阅者
- L2 黑板节点
- L2 字节数
- 检查点
- 注册技能

**左侧 · 业务智能体概览**

标题右侧显示「共 N 个 · 启用 M」。列表按智能体逐行展示：

- 图标（按智能体配置的 icon/color 渲染）+ 右上角状态圆点（绿色＝已启用，灰色＝未启用）
- 智能体名称、业务域（`business_domain`，缺省显示 `—`）
- 技能数标签（仅在挂载了技能时出现，形如「N 技能」）
- 来源标签：`source` 为 `user` 显示「用户态」，其余显示「批处理」

三种空态：后端离线显示「后端离线，智能体列表不可用」；在线但无数据显示「暂无已注册智能体」；列表超高时区域内滚动。

**右侧 · 内核配置**

以键值对形式展示 8 项运行期参数：推理模型、网关地址、最大重试、超时(秒)、最大并行 Agent、最大迭代次数、L1 最大消息数、L2 最大节点字节。后端离线时整块显示「后端离线，配置不可用」。

:::note
本区块只回显网关地址与模型名，**不回显任何密钥**。后端配置快照对密钥字段仅暴露「是否已配置」的布尔标志，管理台无法读取密钥实值。
:::

**右侧 · 内核特性状态**

三条汇总结论：事件总线在线（附订阅者数）、最大并行 Agent（附配置值）、当前推理模型（后端离线时退化为「CoT 推理规划引擎」文案）。

## 关键操作（编号步骤）

1. 从左侧导航进入「运行时内核」，或直接访问 hash `#runtime`。
2. 确认标题右侧徽标为绿色「实时」；若为「示例数据」，先排查后端连通性（见本页最后一节）。
3. 观察「语义内核运行时指标」区块——指标每 5 秒自动刷新，无需手动操作。
4. 与「内核配置」区块交叉比对：若「事件订阅者」为 0，说明当前无 Agent 会话在监听事件总线，通常代表系统空载。
5. 在「业务智能体概览」中核对预期上线的智能体是否全部处于启用状态（绿色圆点），业务域标签是否正确。
6. 如需修改推理模型、并行度、迭代上限或记忆容量，切换到「系统设置」页修改并保存；配置变更会广播刷新事件，本页配置区块随即更新。
7. 若需要下钻查看某条任务在黑板上的节点明细，转到「记忆中心 → L2 黑板」Tab。

## 指标与字段说明

| 指标或字段 | 含义 | 判读建议 |
| :-- | :-- | :-- |
| 事件总线事件数 `events` | 内核启动至今事件总线累计发出的事件条数 | 单调递增。压测或批量任务期间增速明显；长期不变说明系统空载 |
| 事件订阅者 `subscribers` | 当前活跃订阅者数量 | 0 表示无运行中的会话；数值持续攀升且不回落，需怀疑订阅未释放 |
| L2 黑板节点 `l2_nodes` | 共享黑板中的知识节点总数 | 随任务执行增长。突增需结合「记忆中心」核对是否有异常写入 |
| L2 字节数 `l2_bytes` | 共享黑板占用的存储字节数 | 与节点数应大致同步增长；节点数不变而字节数猛涨，说明单节点体积过大 |
| 检查点 `checkpoints` | 已落盘的任务检查点数量 | 检查点是任务可恢复性的基础；长期为 0 说明任务未产生可恢复点 |
| 注册技能 `skills` | 技能注册表中的技能总数 | 应与「技能中心」列表数量一致，不一致说明注册流程异常 |
| 推理模型 `gateway.default_model` | 网关默认推理模型标识 | 与「系统设置」中的选择应一致 |
| 网关地址 `gateway.base_url` | 模型网关的基础地址 | 出现大量超时或重试时，优先核对此项 |
| 最大重试 `gateway.max_retries` | 单次模型调用的最大重试次数 | 过大会放大故障时的延迟，过小会降低抖动容忍度 |
| 超时(秒) `gateway.timeout_seconds` | 单次模型调用超时阈值 | 长上下文或推理型模型需适当放大 |
| 最大并行 Agent `agents.max_parallel_agents` | 同时运行的 Agent 上限 | 该值决定并发吞吐上限；调高需同步评估网关配额 |
| 最大迭代次数 `agents.max_iterations` | 单任务内 Agent 循环的迭代上限 | 防止任务无限循环的硬止损；任务频繁「未完成即结束」可考虑调高 |
| L1 最大消息数 `memory.l1_max_messages` | 单会话保留的最大消息条数 | 决定会话记忆窗口长度，过大将增加每轮的上下文成本 |
| L2 最大节点字节 `memory.l2_max_node_size` | 单个黑板节点允许的最大字节数 | 超限写入会被拒绝；批处理抽取结果偏大时需评估此项 |
| 智能体 `enabled` | 智能体是否启用 | 未启用的智能体不参与调度，也不可被外部调用 |
| 智能体 `source` | 智能体来源：用户态／批处理 | 「用户态」为管理台创建；「批处理」来自后端配置文件声明 |

## 依赖接口

| 方法 | 路径 | 用途 |
| :-- | :-- | :-- |
| GET | `/metrics` | 内核运行时指标（黑板节点/字节、事件数、订阅者、技能数、检查点），页面每 5 秒轮询 |
| GET | `/api/v1/config` | 运行期配置快照（网关、并行度、迭代上限、记忆容量），页面每 30 秒轮询 |
| GET | `/api/v1/agents` | 业务智能体列表（名称、业务域、启用状态、技能、来源），页面每 60 秒轮询 |

三个接口各自独立轮询，任一失败只会让对应区块退化为占位状态，不影响其余区块。

## 排查与注意事项

- **整页显示「示例数据」/「后端离线」**：说明 `/api/v1/config` 请求失败。先在「系统设置」中确认后端地址配置正确，再确认后端进程存活与网络可达。
- **指标区块显示实时、智能体区块显示离线**：`/metrics` 与 `/api/v1/agents` 是两次独立请求，出现这种组合通常是 `/api/v1/agents` 返回了错误状态码，需查看后端日志。
- **注册技能数与「技能中心」不一致**：`/metrics` 的 `skills` 统计的是内核技能注册表，若技能注册时验签失败或被准入流水线拦截，会出现列表可见但未计入注册表的情况，需到「技能中心」查看流水线运行记录。
- **L2 字节数持续增长不回落**：共享黑板为累积型存储，历史任务节点不会自动清理。容量接近规划上限时应安排归档，勿在页面上寻找清理按钮（本页为只读页）。
- **配置改完页面未变**：本页配置区块为 30 秒轮询 + 配置变更事件双触发；若保存后仍未变化，通常是保存请求本身失败或配置需重启方能生效（例如向量维度类参数），请回到「系统设置」查看保存返回结果。
- **智能体状态圆点为灰色**：表示 `enabled` 为 false，该智能体不会被调度。启用操作在「智能体管理」页完成，本页不提供开关。
- **禁止在本页做变更操作**：本页所有区块均为 GET 只读接口，任何「改配置」的诉求都应回到「系统设置」或「智能体管理」，以保证变更留痕。
