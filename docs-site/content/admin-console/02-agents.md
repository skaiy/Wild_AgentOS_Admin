# 智能体管理

## 功能定位

智能体管理页（菜单项「智能体管理」，页面入口 `#agents`）用于创建、配置、测试、发布与删除业务智能体。页面标题为「业务智能体管理」，副标题「管理和监控企业级核心业务智能体」。智能体的能力由四类挂载决定：知识包（决定检索范围）、技能（决定可调用的动作）、基础模型与模型能力槽（决定推理与视觉能力）、MCP 服务（对外工具连接，页面内为只读展示）。

智能体分两类：`source` 不为 `user` 的为「系统批处理 Agent」（后端注册，页面只读展示）；`source` 为 `user` 的为「用户态智能体」（前台创建、已落库，可编辑/测试/发布/删除）。

## 页面结构（区块/Tab/卡片，与代码一致）

| 区块 | 内容 | 可操作性 |

## 关键操作（编号步骤）

1. **创建智能体**：点击右上角「创建新智能体」，依次设置图标与主题色（7 种主题色、14 个图标）、填写名称（必填）、描述、业务领域。
2. **关联知识包**：在「关联知识包」列表勾选一个或多个知识包；列表为空时提示「暂无知识包，请先在「本体层」创建」。运行时将检索所选知识包关联的图谱库与向量库并注入回答。
3. **选择基础模型**：下拉项来自网关实际配置（默认模型 + 模型映射别名），网关默认项带「（网关默认）」后缀；网关未配置模型时显示「（网关未配置模型）」。
4. **配置模型能力槽**：当模型资源注册表存在启用型号时出现「多模型挂载」，可分别为「对话 (chat)」「视觉 (vision)」选择型号；留空表示不挂载，回退基础模型或网关默认。含图片的消息优先走 vision 槽。
5. **挂载技能**：在「挂载技能 Skills（实时注册表）」中按需勾选，每条显示技能名、安全级别徽标、分类与允许角色；已选数量在标题右侧汇总。
6. **保存**：点击「创建智能体」。名称为空时提示「请填写智能体名称」；保存失败时错误信息显示在弹窗底部。保存成功后列表自动刷新。
7. **编辑**：在用户态智能体卡片点击齿轮按钮，表单回填现有配置。仅 `source` 为 `user` 且存在 `id` 的智能体走更新接口，其余情况提交为新建。
8. **测试对话**：点击对话按钮打开抽屉，输入问题回车发送。回答基于该智能体挂载知识包的检索增强问答；系统提示行会给出引用故障码与命中条数、向量库命中条数、未命中知识图谱的降级说明或后端告警。
9. **图片提问**：在测试抽屉点击回形针上传图片（单选，`image/*`），上传成功后以附件标签展示，可点标签内叉号移除；未输入文字直接发送时消息体自动填为「请分析上传的图片」。
10. **处理建议动作**：回答下方出现「建议动作」按钮时点击查看，弹窗显示决策层映射；`requires_business_data=true` 的动作标注「· 规划中」，仅作占位不写库，其余动作提示可在「本体层 → 动作类型」执行器中填写参数后写回知识图谱。
11. **对外发布**：点击火箭按钮打开发布抽屉，点击「未发布（点击发布）」开启对外调用；已发布状态按钮变为「已发布（点击下线）」。抽屉内提供原生接口与 OpenAI 兼容接口的 curl 示例，可一键复制。
12. **授权调用方**：发布抽屉底部列出已授权本智能体的调用方及其状态与密钥数量；为空时提示到「系统设置 → API 密钥治理」新建调用方并勾选该智能体。
13. **删除**：点击垃圾桶按钮，在确认框中确认「此操作不可撤销」后删除，列表自动刷新。

## 字段与参数说明

| 字段 | 含义 | 约束或默认值 |
| :-- | :-- | :-- |
| `name` | 智能体名称 | 必填，保存前去除首尾空格；示例占位「例如：新能源电池维修助手」 |
| `description` | 功能与使用场景描述 | 可选，为空时不提交该字段 |
| `business_domain` | 业务领域标识，用于总览业务域聚合 | 可选，自由输入（示例占位 `battery_repair`） |
| `knowledge_pack_ids` | 关联知识包 ID 列表 | 数组，默认空；决定运行时检索的图谱库与向量库范围 |
| `skills` | 挂载技能的 `skill_iri` 列表 | 数组，默认空；来源为技能注册表实时列表 |
| `icon` | 图标名称 | 默认 `Bot`，取值为内置图标集合中的一项 |
| `color` | 卡片主题色（Tailwind 类名） | 默认 `bg-blue-500`，7 种可选 |
| `version` | 版本号 | 表单默认 `v1.0.0`（展示用，创建/更新请求体不含该字段） |
| `model` | 基础模型 | 下拉取自网关默认模型与模型映射别名 |
| `model_mounts` | 能力槽到型号资源 ID 的映射，如 `chat`、`vision` | 对象，空对象时不提交；槽位留空即从映射中移除并回退基础模型 |
| `enabled` | 是否启用 | 后端字段，卡片以状态点显示（绿色启用 / 灰色停用） |
| `published` | 是否对外发布 | 由发布抽屉切换；已发布卡片显示「已发布」徽标 |
| `source` | 来源 | `user` 为用户态智能体；其他值归入系统批处理 Agent 且不可编辑 |
| 测试消息 `message` | 用户问题文本 | 发送时去除首尾空格；空文本且有图片时替换为「请分析上传的图片」 |
| 测试消息 `images` | 图片直链数组 | 由图片上传接口返回的 `url` 组成，默认空数组 |
| 回答 `grounded` | 是否命中知识图谱 | 为 `false` 时追加系统提示「未命中知识图谱记录，回答基于通用知识」 |
| 回答 `retrieved` / `vector_retrieved` | 图谱命中条数 / 向量库命中条数 | 向量命中大于 0 时追加系统提示并说明已注入上下文 |
| 建议动作 `requires_business_data` | 是否依赖车辆等业务数据 | 为 `true` 时按钮标注「· 规划中」，弹窗提示暂不写回 |

## 依赖接口

| 方法 | 路径 | 用途 |
| :-- | :-- | :-- |
| GET | `/health` | 页头实时徽标 |
| GET | `/api/v1/agents` | 智能体列表（批处理与用户态分组） |
| POST | `/api/v1/agents` | 创建智能体 |
| PUT | `/api/v1/agents/{id}` | 更新智能体配置；发布开关亦通过该接口提交 `published` |
| DELETE | `/api/v1/agents/{id}` | 删除智能体 |
| POST | `/api/v1/agents/{id}/chat` | 测试对话（知识检索增强问答，返回答案、引用与建议动作） |
| POST | `/api/v1/images/upload` | 测试对话图片上传，返回可用于 `images` 的直链 |
| GET | `/api/v1/skills` | 可挂载技能注册表（名称、分类、安全级别、允许角色） |
| GET | `/api/v1/knowledge-packs` | 可关联知识包列表及其分类/图库/向量库计数 |
| GET | `/api/v1/config` | 基础模型下拉项与模型资源注册表（chat / vision 可选型号） |
| GET | `/api/v1/mcp/servers` | 已注册 MCP 工具只读列表与在线状态 |
| GET | `/api/v1/api-clients` | 发布抽屉的授权调用方列表 |
| POST | `/api/v1/public/agents/{id}/chat` | 发布后对外调用的原生同步接口（示例中以 Bearer 密钥鉴权） |
| POST | `/v1/chat/completions` | 发布后对外调用的 OpenAI 兼容接口，`model` 传智能体 ID |

:::warning
对外发布抽屉中的示例仅使用环境变量占位表示密钥，请勿在文档、截图或工单中回填真实密钥。密钥的签发与吊销在「系统设置 → API 密钥治理」完成，明文仅在签发时返回一次。
:::

## 排查与注意事项

- 「后端未连接」占位：智能体列表接口不可用，创建与编辑均无法保存，先恢复后端。
- 关联知识包列表为空：尚未创建知识包，需先在知识中心的「知识包与本体」Tab 创建（页面入口 `#ontology`）。
- 「挂载技能」显示「后端离线，技能列表不可用」或「暂无已注册技能」：分别对应技能接口失败与注册表为空，后者需先在技能中心注册技能。
- 基础模型下拉只有「（网关未配置模型）」：网关未配置默认模型与模型映射，需在系统设置的模型与网关配置中补齐。
- 「多模型挂载」区块不出现：模型资源注册表中没有启用的型号；chat / vision 下拉为空则表示无对应模态的启用型号。
- 编辑系统批处理 Agent：该分组卡片没有操作按钮，其配置由后端注册管理，控制台不提供修改入口。
- 保存报错：错误来自后端返回的 `error` 或 `message`，直接显示在弹窗底部与页面顶部告警条，据此判断是校验失败还是权限不足。
- 测试对话无回复或提示「请求失败」：检查该智能体的基础模型/能力槽是否指向可用型号、网关密钥是否已配置。
- 回答提示「未命中知识图谱记录」：说明检索未命中，需核对挂载的知识包是否关联了正确的图谱库与向量库，以及向量库是否已完成索引。
- 图片上传失败：输入区上方会显示「图片上传失败：…」，常见原因为文件类型不符（仅 `image/*`）或后端对象存储不可用。
- 切换测试对象：更换被测智能体会重置对话记录、输入框、附件与建议动作状态，历史消息不做持久化。
- 已发布但调用返回鉴权失败：确认调用方已在授权列表中、密钥状态为启用，且请求头使用 `Authorization: Bearer` 形式。
