# 平台文档

页面入口：左侧导航「文档中心 → 平台文档」，菜单项 id 为 `docsite`，深链 hash 为 `#docsite`；历史深链 `#documentation` 与 `#manual` 已统一重定向到本页。

## 功能定位

「平台文档」把整套文档站直接内嵌到管理台里，让使用者不切换系统、不额外记地址就能查阅架构说明与操作手册。它解决三件事：

1. **同源同容器**——文档站与管理台由同一个容器、同一个域名提供，页面以子路径 `/docs-site/` 挂载，不存在跨域与额外登录。
2. **一处维护**——文档正文由文档站工程统一维护并随前端一同构建发布，管理台不重复承载文档内容。
3. **双向跳转**——管理台内可直接阅读文档，文档站导航栏也提供「返回管理台」入口。

## 页面结构

页面由三部分组成：

- **页头**：书本图标、标题「平台文档」，副标题「架构与愿景、操作与开发手册、后端内核设计文档（Docusaurus 文档站）」。
- **「新窗口打开」按钮**：位于页头右侧，在浏览器新标签页中打开 `/docs-site/`，适合需要大屏阅读或多页对照的场景。
- **文档站内嵌区**：占据页面剩余高度的内嵌框架，直接加载 `/docs-site/` 首页；后续的目录浏览、搜索、翻页均在该框架内完成。

内嵌的文档站本身包含以下几大板块（由文档站构建时合并生成）：

| 板块 | 内容 |
| --- | --- |
| 项目说明 | 平台定位、总体介绍与快速入门 |
| 版本说明 | 当前版本范围与历史版本变更记录 |
| Agent 开发手册 | 智能体、技能、知识与提示词的开发与操作指引 |
| 前端管理平台 | 管理控制台各功能页的操作文档（即本套章节） |
| 后端内核 | 由后端工程文档目录同步而来的内核设计与实现文档 |

## 关键操作（编号步骤）

1. 在左侧导航「文档中心」分组下点击「平台文档」，或直接访问 hash `#docsite`。
2. 在内嵌框架中使用文档站左侧目录树定位章节；顶部导航提供「系统文档」与「操作与开发手册」两个入口。
3. 需要更大阅读区域或想同时对照多个章节时，点页头右侧「新窗口打开」，在独立标签页中阅读。
4. 在文档站内需要回到管理台时，点文档站导航栏右侧的「返回管理台」——该链接会跳出内嵌框架，直接回到管理台根路径。
5. 在管理台顶部搜索框输入「文档」「架构」「操作手册」「开发手册」等关键词，也可直接跳转到本页。

**文档更新与发布流程**

1. 在文档站工程的正文目录中新增或修改 Markdown 章节（后端内核部分由同步脚本自动从后端工程文档目录复制，不要在文档站里直接改）。
2. 执行文档同步与构建：同步脚本会先合并正文与后端文档、做 MDX 兼容化与对外脱敏处理，再由文档站完成静态构建。
3. 执行管理台的「嵌入文档站」脚本，把构建产物复制到管理台静态资源目录的 `docs-site` 子目录下，并修正文件读取权限。
4. 执行管理台构建（也可直接使用「构建并嵌入文档」的组合命令一步完成第 2–4 步），文档站产物随前端一起打包发布。
5. 发布后进入 `#docsite` 验证：内嵌页能正常加载、目录与新增章节可见、「返回管理台」可用。

## 字段与参数说明

| 名称 | 值 / 位置 | 说明 |
| --- | --- | --- |
| 菜单项 id | `docsite` | 左侧「文档中心」分组下唯一菜单项；也是页面 hash |
| 兼容深链 | `#documentation`、`#manual` | 旧文档页深链，统一渲染为本页 |
| 挂载子路径 | `/docs-site/` | 内嵌框架与「新窗口打开」使用的地址，与文档站构建配置中的站点基础路径一致 |
| 嵌入目标目录 | 管理台静态资源目录下的 `docs-site` | 由嵌入脚本重建并赋可读权限，随前端构建产物一起发布 |
| 后端文档来源 | 后端工程的 `docs` 目录 | 同步脚本优先取中文版本文件，并排除少量不对外的文档 |
| 「返回管理台」 | 文档站导航栏右侧 | 以顶层窗口为目标打开站点根路径，避免在内嵌框架里套娃 |
| 搜索关键词 | 文档 / 平台文档 / 架构 / 愿景 / 操作手册 / 开发手册 / docs / manual | 管理台全局搜索命中本页的词条 |

## 依赖接口

本页为纯静态内嵌页，不调用任何后端业务接口。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/docs-site/` | 内嵌框架与「新窗口打开」加载的文档站首页（同容器静态资源） |
| GET | `/docs-site/*` | 文档站的页面、脚本、样式与静态资源 |
| GET | `/` | 文档站「返回管理台」跳转的管理台根路径 |

## 排查与注意事项

- **内嵌区空白或提示 404**：通常是构建时没有执行嵌入步骤，静态资源目录下缺少 `docs-site` 子目录。重新执行「嵌入文档站」再构建即可。
- **文档站样式或脚本 404**：文档站的站点基础路径必须与挂载子路径 `/docs-site/` 保持一致；改动其一时必须同步另一处，否则资源地址会指向错误前缀。
- **返回 403**：静态文件权限不足。容器内以非 root 身份读取静态资源，嵌入脚本会统一补齐可读权限；手工复制产物时需自行确认权限。
- **改了文档却看不到更新**：先确认执行了文档同步与构建，再排查浏览器缓存与前置缓存层，必要时强制刷新或换用「新窗口打开」验证。
- **内嵌区高度太小**：内嵌框架按页面剩余高度自适应并设有最小高度；若窗口过矮或缩放比例过大，建议改用「新窗口打开」阅读。
- **文档站内的深层链接**：内嵌框架里的跳转不会改变管理台自身的 hash，因此无法通过管理台地址栏分享文档站的具体章节。需要分享时请在新窗口中打开并复制文档站页面地址。
- **正文改动位置**：管理控制台各页操作文档属于文档站自有正文，后端内核部分是同步产物；直接修改同步产物会在下次构建时被覆盖。
