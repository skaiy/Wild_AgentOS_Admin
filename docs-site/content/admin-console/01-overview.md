# 总览（AI Agent 中台总览）

## 功能定位

总览页是管理控制台的首页（菜单项「AI Agent 中台总览」，页面入口 `#overview`），提供智能体、知识、技能、模型与运行时的全平台实时视图。页面所有数值均来自后端实时接口，不含任何演示数据：后端不可通时统一显示占位符「—」并提示「后端未连接」。指标卡与面板右上角的动作链接支持下钻到对应功能页。

页面右上角显示三项状态：运行状态与后端版本号（`v` + `/health` 返回的 `version`）、采样相对时间（由 `/api/v1/memory/unified-stats` 的 `timestamp` 换算为「x 秒前 / x 分钟前 / x 小时前 / x 天前」）、实时徽标（加载中 / 实时 / 异常）。

## 页面结构（区块/Tab/卡片，与代码一致）

| 区块 | 内容 | 下钻目标 |
| :-- | :-- | :-- |
| 关键指标卡（6 张） | 业务智能体、已加载技能、知识库、模型资源、L2 知识节点、校验通过率 | 依次为 `#agents`、`#registry`、`#knowledge`、`#settings`、`#memory`、`#security` |
| 任务执行趋势 | 近 7 天面积图，三条序列：活跃任务 / 执行步 / 完成；副标题显示区间合计 | 无（图表内 Tooltip 与图例） |
| 智能体业务域分布 | 按 `business_domain` 聚合的横向柱状图，Top 8 + 其他 | 「智能体管理」→ `#agents` |
| 记忆分层与知识资产 | L0 长期记忆、L1 会话记忆、L2 黑板、知识库、知识包、本体域、运行时检查点 | 「记忆中心」→ `#memory` |
| 模型与网关 | 默认对话模型、网关端点、Provider、型号资源、生效向量服务、模态覆盖占比条 | 「模型注册中心」→ `#settings` |
| 技能准入与治理 | 技能总数、验签通过、行为校验、Prompt 版本、技能分类分布、安全级别分布 | 「技能中心」→ `#registry` |
| 智能体清单 | 最多展示 8 个智能体，含业务域、技能数、知识包数、「已发布」「启用/停用」徽标 | 无 |
| 集成与对外发布 | MCP 服务数、API 调用方数与密钥总把数、入站调用成功率、最近入站调用（最多 8 条） | 「安全与合规」→ `#security` |
| 运行时快照 | 事件总量、事件订阅者、检查点、最大并行 Agent、单任务最大迭代、校验失败 | 无 |

## 关键操作（编号步骤）

1. 打开控制台首页（或从左侧导航点击「AI Agent 中台总览」），确认右上角显示「系统运行正常」；若显示「后端未连接」，所有数值为「—」，需先恢复后端服务。
2. 查看 6 张关键指标卡，确认智能体/技能/知识库/模型资源规模与校验通过率；卡片副标题给出关键分解（如「已发布 N」「向量 N · 图 N」「Provider N」）。
3. 点击任意指标卡下钻到对应功能页（如点击「知识库」跳转知识中心 `#knowledge`）。
4. 在「任务执行趋势」中核对近 7 天任务量与完成量的走势；曲线为空且提示「后端未连接」时说明趋势接口不可用。
5. 在「智能体业务域分布」中定位业务域分布失衡（超过 8 个业务域时其余合并为「其他」，超长标签自动截断为 16 字 + 省略号）。
6. 在「模型与网关」核对默认对话模型与「密钥已配置 / 缺少密钥」提示，以及「生效向量服务」的 provider 与维度；发现缺配时点击「模型注册中心」处理。
7. 在「技能准入与治理」核对验签通过数与「未签名 / 异常」数量；存在异常时点击「技能中心」查看明细。
8. 在「集成与对外发布」检查入站调用成功率与最近调用的端点、耗时、HTTP 状态；成功率异常时点击「安全与合规」排查调用方与密钥。
9. 页面各区块按自身轮询周期自动刷新（见下表），无需手动刷新页面。

## 字段与参数说明

| 字段 | 含义 | 约束或默认值 |
| :-- | :-- | :-- |
| 业务智能体 | 智能体总数（`/api/v1/agents` 的 `agents` 长度） | 副标题为 `published=true` 的数量；轮询 60 秒 |
| 已加载技能 | 技能注册表条数；为 0 时回退 `/metrics` 的 `skills` | 副标题为 `signature_status=verified` 的数量；轮询 30 秒 |
| 知识库 | 知识库条数；为 0 时回退统计接口 `knowledge_bases.total` | 副标题按 `kb_type` 拆分为向量 / 图；轮询 30 秒 |
| 模型资源 | 模型资源注册表 `models.resources` 条数 | 副标题为 `models.providers` 条数；轮询 30 秒 |
| L2 知识节点 | `/metrics` 的 `l2_nodes`，回退 `memory_tiers.l2_blackboard.nodes` | 副标题为 `l2_bytes` 的人类可读体积（B/KB/MB/GB）；轮询 5 秒 |
| 校验通过率 | `pass_rate` 百分比（保留 1 位小数） | `total_checks` 为 0 时显示「—」；`failed_checks` 大于 0 时卡片转为告警色；轮询 8 秒 |
| 活跃任务 / 执行步 / 完成 | 趋势点的 `tasks` / `checkpoints` / `completed` | 取自持久化检查点按天聚合；默认 `days=7`，轮询 30 秒 |
| 业务域 | 智能体 `business_domain`，为空时回退智能体名称，再回退「未分类」 | 图表取 Top 8，其余并入「其他」；标签超过 16 字截断 |
| L0 / L1 / L2 / L3 | 长期记忆条数、会话数、黑板节点与任务数、投影数 | L1 / L3 当前无枚举接口，返回 `null` 时显示「N/A」 |
| 本体域 | 统计接口 `ontology.domain`，右侧为对象类型数 | 副标题给出链接类型数与动作类型数 |
| 默认对话模型 | 网关 `gateway.default_model` | 未配置时显示「未配置」；副标题为「密钥已配置 / 缺少密钥」 |
| 网关端点 | 由 `gateway.base_url` 解析出的主机名 | 副标题为 `timeout_seconds` |
| Provider | 启用数 / 总数 | 副标题为已配置密钥的 Provider 数 |
| 型号资源 | 启用数 / 总数 | 副标题按 `modalities` 聚合，缺省模态记为 `chat` |
| 生效向量服务 | `embedding.provider` | 副标题为 `active_dimension` 维；`enabled=false` 时追加「已禁用」 |
| 入站调用成功率 | 最近审计记录中 HTTP 状态 200–399 的占比 | 取最近 20 条（`limit=20`）；副标题为平均耗时毫秒 |
| 最大并行 Agent / 单任务最大迭代 | `agents.max_parallel_agents` / `agents.max_iterations` | 运行时配置只读展示，修改在系统设置页进行 |

## 依赖接口

| 方法 | 路径 | 用途 |
| :-- | :-- | :-- |
| GET | `/health` | 后端在线状态与版本号 |
| GET | `/metrics` | L2 节点数与字节数、事件、订阅者、技能数、检查点 |
| GET | `/api/v1/memory/unified-stats` | 记忆分层、知识库/知识包、本体域、运行时统计与采样时间 |
| GET | `/api/v1/tasks/trends?days=7` | 任务执行趋势按天聚合序列 |
| GET | `/api/v1/config` | 网关、向量服务、模型注册表、并发与迭代上限 |
| GET | `/api/v1/agents` | 智能体清单、业务域分布、发布与启用状态 |
| GET | `/api/v1/skills` | 技能总数、分类与安全级别分布、验签状态、可信密钥数 |
| GET | `/api/v1/guard/stats` | 行为校验总数、通过数、失败数与通过率 |
| GET | `/api/v1/kb/bases` | 知识库条数与向量/图类型拆分 |
| GET | `/api/v1/knowledge-packs` | 知识包数量 |
| GET | `/api/v1/mcp/servers` | 已注册 MCP 服务数量 |
| GET | `/api/v1/prompts` | Prompt 版本数与是否存在生效版本 |
| GET | `/api/v1/api-clients` | API 调用方数量与名下密钥数量 |
| GET | `/api/v1/api-audit?limit=20` | 最近入站调用记录（端点、状态、耗时） |

:::note
`/api/v1/api-clients` 与 `/api/v1/api-audit` 属管理面接口，需具备管理角色的身份头；权限不足时「API 调用方」一行会显示「需管理员权限」，其余区块不受影响。
:::

## 排查与注意事项

- 全页显示「—」且状态点为琥珀色：后端不可达。先确认后端服务与控制台配置的后端地址，再刷新。
- 部分区块单独显示「后端未连接」：说明该区块依赖的单个接口失败（例如仅趋势图为空即 `/api/v1/tasks/trends` 异常），按上表逐个核对接口。
- 「校验通过率」为「—」：说明 `total_checks` 为 0，即尚无行为校验样本，属正常初始状态。
- 「L1 会话记忆」「L3 投影」显示「N/A」：后端当前不提供该层枚举接口，返回 `null`，非故障。
- 「知识库」「已加载技能」卡片出现 0 值回退：卡片先取列表长度，列表为空才回退聚合统计字段，两者短暂不一致属轮询周期差异（技能 30 秒、指标 5 秒、智能体 60 秒）。
- 业务域图表出现「其他」或末尾省略号：业务域为自由输入字段，图表做了 Top 8 合并与 16 字截断，完整值请在智能体管理页查看。
- 修改系统设置后总览未变：配置保存会广播刷新事件，各区块会重新拉取；若仍未变化，等待一个轮询周期或重新进入页面。
- 「入站调用成功率」显示「暂无调用」：审计记录为空，通常是尚未有调用方通过入站密钥访问已发布智能体。
