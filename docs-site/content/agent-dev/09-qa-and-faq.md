# QA 验收与常见问题

## 1. 验收清单

| 功能 | 检查点 |
| :-- | :-- |
| Agent 增删改 | 创建、编辑、删除与刷新后数据一致 |
| Skill | 应用级 Skill 可创建与编辑，系统级 Skill 保持只读，流水线状态可查询 |
| 知识库 | 分类、向量库、图谱库与知识包引用关系正确 |
| 图谱导入 | 来源数、记录数、三元组数与必要字段符合导入清单 |
| RAG | 已收录问题命中知识；未命中时状态与提示明确 |
| 模型 | Provider 型号发现、连通性测试与 Agent 实际路由一致 |
| Prompt | 激活版本唯一，灰度 resolve 结果符合配置 |
| 任务 | SSE、状态、计划与执行明细可查看 |
| 安全 | 密钥脱敏、越权请求被拒、审计记录可查询 |
| 重启恢复 | Agent、知识、Skill、Prompt 与模型配置按设计恢复 |

## 2. 示例业务验证流程（新能源车维修智能体）

1. 在智能体管理确认已挂载知识包、业务 Skill 与 `chat` 能力槽。
2. 在知识中心确认知识包指向全量维修图谱。
3. 使用 SPARQL 查询一个已知故障码，确认图谱中存在对应实体。
4. 在 Agent 测试中提问该故障码的含义与能否继续行驶。
5. 检查响应的 `status`、`model`、`grounded`、`retrieved`。
6. 对照图谱中的含义、行驶建议与来源页面核对回答。

## 3. 常见问题

| 现象 | 检查项 |
| :-- | :-- |
| 写操作返回 403 | 严格模式是否开启、调用身份角色是否满足接口要求 |
| Agent 没有知识命中 | 知识包 ID、图谱库 ID、命名图数据、问题中的关键实体 |
| 模型测试失败 | Provider 地址、密钥、真实模型名与网络可达性 |
| 对话返回 `degraded` | 模型调用错误详情，确认能力槽资源可用 |
| 向量查询无结果 | Embedding 是否启用、维度是否一致、文档是否完成索引 |
| SPARQL 查询为空 | 命名图、IRI、属性路径与导入批次 |
| SSE 无输出 | 代理缓冲、连接超时与任务状态 |
| 重启后配置缺失 | 后端工作目录与数据目录文件权限 |
| 配置保存后模型资源变少 | `models` 段为整体替换语义，需提交完整集合 |
| 大图谱可视化卡顿 | 先用 SPARQL 或子图筛选后再渲染 |
